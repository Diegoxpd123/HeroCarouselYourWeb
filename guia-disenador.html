Hero Carousel — Guía para diseñadores

Este documento explica cada campo que puedes configurar en Wix (Set Attributes), cómo agregar más slides y cómo ocultar piezas.

Tag del elemento: yourweb-hero-carousel
En Wix: Custom Element → Server URL del script → Tag name = yourweb-hero-carousel → Set Attributes.
Cómo usarlo en Wix Agregar / quitar slides Cómo ocultar cosas Campos por slide Campos globales Animación Tamaño y posición Ejemplo completo

1. Cómo usarlo en Wix

  1. Agrega un Custom Element.
  2. Pega la URL del script (jsDelivr / GitHub).
  3. Tag name: yourweb-hero-carousel.
  4. En Set Attributes agrega pares Name / Value (ej. Name: brand, Value: PETCARE).
  5. Estira el Custom Element al tamaño que quieras: el hero llena ese espacio.
Todos los campos son opcionales. Si no pones nada, se ven 4 slides demo.

2. Cómo agregar o quitar slides

Los slides son ilimitados. Solo sube el número: 1, 2, 3, 4, 5, 6…

Agregar un slide nuevo (ej. el #5)

En Set Attributes crea estos campos (mínimo la imagen o video):

image-5 = https://tu-cdn.com/mascota-5.png
bg-5 = #9B59B6
label-5 = Kira
caption-5 = Nutrición
title-5 = Plan nutricional

Agregar el #6, #7, etc.

Igual: image-6, bg-6, label-6…

Quitar un slide

Borra sus atributos en Wix (image-5, bg-5, etc.). Si dejas un “hueco” en la numeración, el componente toma el número más alto que exista (ej. si hay 1–3 y 5, cuenta hasta 5).

Importante: en pantalla se ven máximo 4 figuras a la vez (centro, izquierda, derecha, atrás). Si tienes 8 slides, los demás entran al rotar el carrusel.

3. Cómo ocultar cosas

Qué quieres ocultarQué poner en Set Attributes
Botón CTA (Agendar, etc.) No agregues cta-label (si no existe, no se muestra)
Flechas ‹ › controls = off default: ocultas
Textura grain (ruido) grain = off
Autoplay (que no rote solo) autoplay = off
Texto brand (arriba izquierda) Pon brand = un espacio , o el texto que quieras. No hay “hide” dedicado; si no quieres verlo, usa un espacio o pídele a desarrollo ocultarlo.
Puntos indicadores (dots) En móvil ya se ocultan solos. En desktop siempre se muestran (si hace falta ocultarlos, pedirlo a desarrollo).
Valores típicos de encendido/apagado: on / off (también sirve true/false).

4. Campos por cada slide (N = 1, 2, 3…)

NameQué esDefault / nota
image-N / video-N / media-N Media del personaje Demo SVG si no pones nada
bg-N Color de fondo del hero cuando ese slide está activo Colores demo (coral, verde, rosa, azul…)
panel-N Color de panel asociado al slide Opcional
label-N Nombre corto (ej. Luna) Se ve arriba del título como “Luna / Chequeo…”
caption-N Frase corta al lado del label Ej. “Chequeo preventivo”
title-N Título grande de ese slide Si no existe, usa el title global 
label-1 = Luna
caption-1 = Chequeo preventivo
title-1 = Cuidado moderno
bg-1 = rgb(244, 132, 95)
image-1 = https://…/luna.png

5. Campos globales (de toda la sección)

NameQué esDefault
brand Texto arriba a la izquierda YOURWEB HERO
title Título general (fallback si no hay title-N) Hero animado configurable

text-color Color del texto #fff
button-bg Fondo del CTA #fff
button-text Texto del CTA #171717

6. Animación y controles

NameValoresDefaultNota
autoplay on / off on Pausa al pasar el mouse
interval milisegundos 1000 1000 = 1 segundo. Mínimo útil ~400
transition-ms milisegundos 650 Duración del movimiento
controls on / off off Flechas prev/next
grain on / off on Textura de película
También se puede navegar con teclado (← →) y swipe en móvil.

7. Tamaño y posición (avanzado)

Úsalos si quieres afinar el layout. Aceptan %, px, clamp(), etc.

Alto del bloque

  • height — default 100% (llena el Custom Element)
  • min-height — default 320px
  • title-size — tamaño del H1

Figuras (alto / escala)

  • center-height / -desktop / -tablet / -mobile
  • side-height (+ breakpoints)
  • back-height (+ breakpoints)
  • center-scale, side-scale, back-scale

Posiciones

  • Desktop: center-bottom, side-bottom, back-bottom, left-pos, right-pos, stage-center
  • Mobile: mismos con sufijo -mobile (ej. left-pos-mobile)
En la mayoría de casos basta con redimensionar el Custom Element en Wix y no tocar estas variables.

Checklist rápido para el diseñador

  • ☐ ¿Cuántos slides? → crea image-1…image-N
  • ☐ ¿Color de cada slide? → bg-N
  • ☐ ¿Textos? → label-N, caption-N, title-N
  • ☐ ¿Botón? → solo si hay cta-label (+ cta-href)
  • ☐ ¿Sin flechas? → deja controls en off o no lo pongas
  • ☐ ¿Sin autoplay? → autoplay=off
  • ☐ ¿Sin grain? → grain=off
